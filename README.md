This directory contains supplementary files for H2X100: A Gold-Standard CCSD(T)/CBS Benchmark Dataset of Binding Energies, Structures, and Harmonic Frequencies for (H2X)n, X = S, Se, Te, n = 2–4, and Assessment of Lower-Scaling Density Functional Theory Methods.

For each DFT method, you will find the corresponding structures of each dimer discussed in the main text, optimized with that DFT method, along with its electronic energy and rotational constants.

You will find a corresponding .csv file for each functional in the binding energies directory, and likewise in the harmonic frequencies directory.

Finally, most importantly, the coordinates for the 100 clusters are found in mp2_haqz_reference_geometries.
